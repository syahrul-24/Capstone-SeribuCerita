# 📊 Dashboard Analisis Emosi Tweet

Dashboard ini merupakan aplikasi interaktif berbasis Streamlit untuk menganalisis emosi pada dataset tweet. Proyek ini mencakup eksplorasi data, visualisasi, feature engineering, serta A/B testing sederhana antara emosi *happy* dan *sad*.


## 🚀 Fitur Utama

### 📄 Penjelasan Proyek
- Latar belakang analisis emosi pada teks tweet
- Tujuan dan pendekatan analisis data dari awal hingga akhir pipeline

### Dashboard Analisis
- Ringkasan dataset (jumlah data, jumlah label, rata-rata kata)
- Distribusi emosi (bar chart dan pie chart)
- Analisis ketidakseimbangan data
- Statistik feature engineering (jumlah kata & panjang karakter)
- A/B Testing emosi *happy* vs *sad*

## 📁 Dataset

Dataset yang digunakan harus memiliki kolom:
- text
- label
- jumlah_kata
- panjang_karakter

File dataset:
- output_data_final.csv
